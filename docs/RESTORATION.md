## 处理过程

1. 去除 Markdown 表格外框与分隔行；把 Markdown 链接恢复为原链接标签内容，把反斜杠转义恢复为代码字符。

3. 结合旧源码与作用域分析，恢复全局和局部变量的语义命名，避免全局字符串替换误伤同名单字母变量。

6. 以相同词典、时间、随机序列和输入，比较压缩版与恢复版的浏览器执行结果。

## 保留的原有问题

以下均能直接从附件代码确认。本次以还原为目标保留其行为，建议后续在单独改动中修复，修复时应更新相应回归预期。

| 问题                                             | 当前实际行为 / 后续影响                                                                                                                         |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 帮助写每轮随机 25 词                             | 代码按进度截取 20 词，只在启用乱序后打乱这一组的顺序                                                                                            |
| 布尔默认值写成 `getItem(...) === "true" ?? true` | 比较结果已经是布尔值，`?? true` 不生效；无存储时乱序和释义朗读实际关闭                                                                          |
| 大写开关仅重新开始练习                           | 大写转换发生在词典加载阶段，开关变更不会即时重建词典；重新加载词典或页面才反映设置                                                              |
| 帮助写连续正确 3 次掌握                          | 代码累计答对次数并检查 `> 3`，即第 4 次；错误不清零，开始新一轮也不重置累计表                                                                   |
| 复习完成判断固定读取 `unKnownWords.basic`        | 在四级词典复习时，完成判断仍受基础词典错词列表影响                                                                                              |
| 最后一个词的跳过分支直接结束                     | 不把最后一词加入错词库；错误触发跳过时，练习记录可能先于失败计数更新                                                                            |
| 进度上限使用 `Math.floor`                        | 四级词典 2607 词按每组 20 计算为 130 级，末尾 7 词没有独立级别                                                                                  |
| 复习切换中的 `this.blur()`                       | 按钮点击时 `this` 是按钮，普通函数调用时是 `window`，会调用窗口的 `blur()`；若直接改成严格模式或 ES module，则可能因 `this` 为 `undefined` 抛错 |
| 开始时重复调用音频播放                           | 同时调用 `updateWord` 内播放和额外播放，音频结束回调可能互相覆盖；停止后也没有统一的异步取消机制                                                |
| 返回上一词复用“下一词音频”缓存                   | 显示单词和播放音频可能不一致；完成计数也可能出现不符合预期的递减                                                                                |
| 标记已掌握的词没有用于后续选词过滤               | `knownWords` 会保存，但只移除本轮相同词；后续仍可能选到                                                                                         |
| 帮助写 Shift+Esc 切换释义模糊                    | 键盘处理没有检查 Shift，实际仍执行 Esc 的隐藏单词操作                                                                                           |
| 释义模糊设置启动时只恢复复选框                   | 页面加载时未同步 `.paraphrase` 的模糊类，需操作开关后才反映                                                                                     |
| 词性正则未转义点号、较短缩写排在前面             | 部分释义的词性标签可能匹配错误                                                                                                                  |
| 烟花备用分支引用 `initAndResize`                 | 附件没有定义该函数，且空画布检查发生在 `getContext` 之后；正常页面有画布时不进入该分支                                                          |
